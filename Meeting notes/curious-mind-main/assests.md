# Project Assets

This file records visual and other supporting assets used in the Curious Mind: AI Overview project. The inventory below must be updated when real assets are added. Do not list planned assets as if they already exist.

## Asset guidelines

1. Use visuals that directly support a learning objective.
2. Ensure labels and text remain readable at the intended size.
3. Record the creator/source and applicable licence or permission.
4. Attribute externally sourced material according to the licence and course requirements.
5. Do not include private, confidential, or sensitive personal information.
6. Use descriptive filenames and keep assets organized in a dedicated folder when appropriate.
