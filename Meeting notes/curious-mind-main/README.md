# Curious Mind: AI Overview

## Project overview

**Curious Mind: AI Overview** is a beginner-friendly learning module introducing artificial intelligence (AI), machine learning, generative AI and large language models, real-world applications, responsible use, and practical evaluation skills.

The repository contains six topic chapters and supporting planning, revision, and assessment materials. A plan, outline, or script should not be mistaken for a completed slide deck or recorded video; check the deliverable requirements in the assignment brief before submission.

## Learning objectives

By the end of the module, learners should be able to:

1. Define AI and explain its relationship to machine learning and deep learning.
2. Describe data, model training, evaluation, and prediction at an introductory level.
3. Explain generative AI and large language models in plain language.
4. Identify AI applications and weigh possible benefits against limitations.
5. Recognize risks involving bias, privacy, accuracy, fairness, and accountability.
6. Improve prompts and evaluate AI-generated information using independent evidence.
7. Use AI tools in accordance with academic-integrity rules and human oversight.
